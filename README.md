# Lancement en local
Aller dans le dossier `shunpo-app` et lancer les commandes suivantes :
```
cd shunpo-app
cp .env.example .env.local
npm run dev
```
Remplir les variables d'environnement dans le fichier `.env.local` avec l'url Supabase Vite et la clé API publishable.
